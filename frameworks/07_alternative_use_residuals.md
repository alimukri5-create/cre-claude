# Alternative-use residuals
For each other use (storage, co-living, hotel, showroom, studio/lab, industrial, owner-occupier): residual land value after build cost, fees, finance, planning charges (CIL, S106) and developer profit. Convert to a bid today.
Reject any use that ignores future supply (the storage mistake). Replacement cost only counts if someone would actually build. Check how neighbours actually built (e.g. mezzanines outside CIL).
Output: table of use, residual, bid today, confidence.
