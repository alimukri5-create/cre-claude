# Hard floor (Fukuoka Dome test)
Ignore the building as an office. Add up only what is certain or physical: contracted rent to lease end, rent deposit/dilapidations, and bare land value net of demolition.
Compare that undiscounted cash with the all-in cost (price + SDLT + fees).
Find: (a) the price at which the floor returns 100% of the money; (b) the money still at risk after rent ends, and how many times land value and empty-building value cover it.
Output: floor table, break-even price, cover ratio. Flag every input as SOURCED/ESTIMATE/UNVERIFIED.
